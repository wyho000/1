# Flywire Lab · 초파리의 작은 세계

암컷 초파리의 실제 해부학 데이터와 감각 기반 자율 행동을 결합한 브라우저 시뮬레이션입니다. 초파리를 직접 조종하지 않고, 화학물질 환경을 바꾸면서 행동과 모의 신경 활동을 관찰합니다.

## 실행

Node.js 22 이상이 필요하며 **Node.js 24 LTS**를 권장합니다. GitHub에서 **Code → Download ZIP**을 선택하고 압축을 푼 뒤, **`package.json`이 있는 폴더**에서 터미널을 여세요.

```sh
npm ci
npm run dev
```

개발 서버는 포트 5173에서 실행됩니다. **명령을 실행한 PC의 브라우저 주소창에 `localhost:5173`을 입력하세요.** 실행하는 동안 터미널을 열어 두고, 종료하려면 Ctrl+C를 누릅니다. 다음 실행부터는 `npm run dev`만 입력하면 됩니다.

Windows PowerShell에서 `npm.ps1` 실행이 차단되면 명령 프롬프트를 사용하거나 `npm.cmd ci`, `npm.cmd run dev`를 실행하세요. 포트 5173이 이미 사용 중이면 `npm run dev -- --port 5174`로 실행하고 브라우저에서 `localhost:5174`를 엽니다. `index.html`을 더블클릭하는 방식으로는 실행하지 않습니다.

처음 패키지를 설치할 때 인터넷 연결이 필요합니다. API 키, 데이터베이스, Python은 기본 실행에 필요하지 않습니다. 뉴런 데이터와 폰트는 로컬로 제공하며 실행 중 외부 데이터 서비스에 연결하지 않습니다. 자세한 순서는 [PC 실행 안내](PC-실행안내.txt)를 참고하세요.

`/workspace/1`은 개발에 사용한 **클라우드 경로**이며 개인 PC의 경로가 아닙니다. 클라우드 작업 공간에서는 해당 폴더에서 같은 명령을 실행하면 됩니다.

```sh
npm test       # 자율 이동, 감각, 기억, 결정성, 수치 안정성 검증
npm run build # TypeScript 검사 및 배포용 dist 생성
npm run preview # 빌드한 앱 확인, 기본 포트 4173
```

현재 환경의 Chromium과 Python Playwright로 실제 브라우저 조작도 확인할 수 있습니다. 먼저 개발 서버를 실행합니다.

```sh
python3 scripts/browser-smoke.py
```

다른 환경에서는 Python `playwright`와 Chromium이 추가로 필요합니다. `FLYWIRE_BASE_URL`과 `FLYWIRE_CHROMIUM_PATH`로 검사 주소와 브라우저 경로를 지정할 수 있습니다. 기본 앱 실행과 단위 테스트에는 필요하지 않습니다.

## 조작

- **화학물질**: 에틸 아세테이트(먹이 유인), 벤즈알데하이드·이산화탄소(이 모델의 회피 자극)를 최대 6개 배치합니다. 스위치로 각 발생원을 켜고 끕니다.
- **방출량·거리·확산**: 선택한 물질의 슬라이더로 조절합니다. 거리는 현재 초파리 위치를 기준으로 발생원을 이동시키며, 이후 초파리가 움직이면 다시 변합니다. 공간 경계에서는 위치가 제한됩니다.
- **위치**: 발생원을 드래그하거나 지도 빈 곳을 누릅니다. X/Y 입력으로 키보드 조절도 가능합니다. 초파리의 위치는 조작하지 않습니다.
- **관찰**: 일시정지, 초기화, 0.5–4배속, 이동 경로와 농도장 표시를 제공합니다. 일시정지 중에도 환경은 편집할 수 있고, 재생하면 변경한 자극에 반응합니다.
- **뇌 지도**: 오른쪽 아래에서 실제 뉴런 위치 표본과 영역별 모의 활성도를 봅니다. 영역을 클릭하거나 Tab과 Enter/Space로 선택하면 이름·역할·활성도를 확인합니다.
- **기록 저장**: 현재 환경, 난수 시드, 초파리 상태, 활성도, 최근 행동 이벤트를 JSON으로 다운로드합니다. 전체 세션 시계열 녹화가 아닌 현재 실험의 스냅샷입니다.

## 데이터와 모델의 범위

뇌 지도는 **FlyWire FAFB 성체 암컷 v783**, 주석 릴리스 **v2.0.0**의 139,255개 뉴런 중 실제 위치 7,000개를 결정적으로 표본 추출해 표시합니다. 원본 ID, 뉴런 분류, 출처, SHA-256 검증 정보를 함께 제공합니다. [자세한 출처와 재생성 방법](docs/data-provenance.md)을 참고하세요.

점은 뉴런의 anchor 좌표를 투영한 것이며 전체 신경 형태나 시냅스 위치가 아닙니다. 강조 영역은 뉴런군 중심점이고 정확한 해부학적 영역 경계가 아닙니다. 표본은 관심 회로를 강조하므로 실제 뉴런 밀도를 대표하지 않습니다.

**행동·활성도·연결선은 설명용 축약 모델입니다. 실제 시냅스 연결 가중치를 계산하거나 139,255개 뉴런을 개별 재현하지 않으며, 의식이나 실제 사고의 재현을 주장하지 않습니다.** 전체 시냅스 데이터는 이 실행 환경의 접근 제한으로 확보하지 못했으며, 가상의 연결 데이터를 실제 관측치처럼 사용하지 않았습니다.

행동 엔진은 양쪽 더듬이의 국소 농도와 시간 변화, 최근 냄새의 친숙도, 허기, 경계 감각, 시드 기반 탐색 잡음을 사용합니다. 발생원의 방향을 직접 읽어 목표 좌표로 이동하지 않습니다. MB의 감각 기억·새로움이 탐색을 조절하고, CX의 방향 상태와 DN의 운동 출력이 실제 회전·속도에 연결됩니다. 농도장은 가우시안으로 근사하고 방출량·활성도는 상대값이며, mm는 가상 공간의 환산 척도입니다.

## 구성

```text
src/simulation.ts             감각·기억·자율 행동 엔진
src/components/WorldCanvas.tsx 실험장, 농도장, 발생원 드래그
src/components/BrainMap.tsx   실제 뉴런 좌표와 모의 활성 지도
src/App.tsx                   실험 조작·관측·기록 저장
public/data/flywire-brain.json 출처가 포함된 로컬 해부학 데이터
scripts/build-brain-data.py   원본 검증 및 표본 데이터 재생성
tests/simulation.test.ts      행동 및 모델 검증
scripts/browser-smoke.py      데스크톱·모바일 기능 검증
```

출처: Schlegel et al. (2024), *Whole-brain annotation and multi-connectome cell typing of Drosophila*; Dorkenwald et al. (2024), *Neuronal wiring diagram of an adult brain*. 자세한 인용·이용 조건은 데이터 출처 문서에 있습니다.
