Flywire Lab — PC에서 실행하기

1. https://nodejs.org 에서 Node.js 24 LTS를 설치하세요.
2. GitHub에서 Code → Download ZIP을 선택하고 압축을 푸세요.
3. 압축을 푼 폴더 중 package.json이 있는 폴더에서 터미널을 여세요.
   Windows: 탐색기로 해당 폴더를 열고 주소창에 cmd를 입력한 뒤 Enter.
   macOS: 터미널에 cd와 공백을 입력한 뒤 해당 폴더를 끌어 놓고 Enter.
4. 아래 명령을 순서대로 실행하세요.

   node --version
   npm --version
   npm ci
   npm run dev

5. 같은 PC의 브라우저 주소창에 localhost:5173 을 입력하세요.
6. 실행 중 터미널은 열어 두세요. 종료하려면 Ctrl+C를 누릅니다.

Windows PowerShell에서 npm.ps1 실행 정책 오류가 나면:
   npm.cmd ci
   npm.cmd run dev

포트 5173이 이미 사용 중이라면:
   npm run dev -- --port 5174
브라우저 주소창에는 localhost:5174 를 입력하세요.

다음부터는 같은 폴더에서 npm run dev만 실행하면 됩니다.
index.html을 더블 클릭하는 방식은 지원하지 않습니다.
최초 npm ci에는 인터넷 연결이 필요합니다.
API 키, Python, 추가 뇌 데이터 다운로드는 필요하지 않습니다.
/workspace/1은 클라우드 경로이며 PC의 폴더 경로가 아닙니다.

초파리는 스스로 움직입니다. 왼쪽 패널에서 물질의 양, 거리, 확산 범위를
조절하거나 지도에서 물질을 끌어 옮기세요. 오른쪽 아래 뇌 지도의 점은
실제 FlyWire 암컷 뉴런 좌표이며, 활성도와 행동은 단순화한 모델입니다.
