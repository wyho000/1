Flywire Lab — PC에서 실행하기

1. https://nodejs.org 에서 Node.js 24 LTS를 설치하세요.
2. GitHub에서 Code → Download ZIP을 선택하고 압축을 푸세요.
3. 압축을 푼 폴더 중 package.json이 있는 폴더에서 터미널을 여세요.
   Windows: 탐색기로 해당 폴더를 열고 Ctrl+L을 누른 뒤 cmd를 입력하고 Enter.
   또는 폴더의 빈 공간을 우클릭하고 '터미널에서 열기'를 선택하세요.
   macOS: 터미널에 cd와 공백을 입력한 뒤 해당 폴더를 끌어 놓고 Enter.
4. 아래 명령을 순서대로 실행하세요.

   node --version
   npm --version
   npm ci
   npm run dev

5. 같은 PC의 브라우저 주소창에 localhost:5173 을 입력하세요.
6. 실행 중 터미널은 열어 두세요. 종료하려면 Ctrl+C를 누릅니다.

Windows PowerShell에서 npm.ps1 실행 정책 오류가 나면:
   npm.cmd ci
   npm.cmd run dev

포트 5173이 이미 사용 중이라면:
   npm run dev -- --port 5174
브라우저 주소창에는 localhost:5174 를 입력하세요.

다음부터는 같은 폴더에서 npm run dev만 실행하면 됩니다.
index.html을 더블 클릭하는 방식은 지원하지 않습니다.
최초 npm ci에는 인터넷 연결이 필요합니다.
API 키, Python, 추가 뇌 데이터 다운로드는 필요하지 않습니다.
/workspace/1은 클라우드 경로이며 PC의 폴더 경로가 아닙니다.

초파리는 스스로 움직입니다. 왼쪽 패널에서 물질의 양, 거리, 확산 범위를
조절하거나 지도에서 물질을 끌어 옮기세요. 오른쪽 아래 뇌 지도의 점은
실제 FlyWire 암컷 뉴런 좌표이며, 활성도와 행동은 단순화한 모델입니다.

이미 실행했던 버전을 새 버전으로 바꾸기

1. 이전 프로그램을 실행한 터미널에서 Ctrl+C를 눌러 종료하세요.
2. GitHub의 flywire-simulator 브랜치에서 ZIP을 다시 다운로드하세요.
3. 기존 폴더와 구분되는 새 폴더에 압축을 푸세요.
4. 새 폴더에서 package.json이 보이는 위치로 들어가 터미널을 여세요.
5. Windows에서는 다음 명령을 하나씩 실행하세요.

   npm.cmd ci
   npm.cmd run dev

6. 브라우저에서 localhost:5173을 새로고침하세요.

Node.js가 이미 설치되어 있으면 다시 설치하지 않아도 됩니다.
GitHub의 파일 변경이 이미 내려받은 PC 파일에 자동 적용되지는 않습니다.

추가한 조건: 2-페닐에탄올 0.01/0.05/0.1%, 에탄올 1/5/10%,
아세트산 0.1/0.5/1%, DW, 1× PBS buffer입니다.
왼쪽 목록에서 조건을 선택하고 +를 눌러 배치하세요.
용액 농도는 실제 기체 농도가 아니며, 새 물질의 유인·회피는 조절 가능한
모델 가정입니다. DW와 PBS는 후각 입력이 없는 대조군으로 처리합니다.

화학물질을 그대로 두고 초파리만 다시 시작하기

관찰 공간 아래의 '초파리만 초기화' 버튼을 누르세요.
배치한 물질의 위치, 농도, 양, 반응 설정과 켜짐 상태는 그대로 유지됩니다.
초파리는 중앙으로 돌아오고 기억, 허기, 신경 활동, 시간과 기록이 초기화됩니다.
시작할 때 바라보는 방향과 탐색 움직임은 매번 무작위로 새로 정합니다.
일시정지 중이었다면 그대로 멈추며, 재생 중이었다면 중앙에서 다시 움직입니다.
오른쪽 '전체 초기화' 버튼은 화학물질 배치도 처음 상태로 되돌립니다.

양쪽에 유인 물질을 놓고 비교하기

1. 일시정지한 뒤 기본 에틸 아세테이트와 벤즈알데하이드의 스위치를 끄세요.
2. 같은 물질과 농도를 두 개 추가하고 양, 확산 범위, 반응 설정도 같게 맞추세요.
3. 두 물질의 X/Y를 각각 25/35와 75/35로 입력하세요. 단위는 mm입니다.
   초파리는 중앙 50/35에서 시작하므로 두 물질까지의 거리가 같습니다.
4. 일시정지 상태에서 '초파리만 초기화'를 누른 뒤 재생하세요.
   정한 시간에 다시 일시정지하고 기록을 저장하세요.
5. 여러 번 반복하세요. 서로 다른 조건을 비교할 때는 좌우 위치도 바꿔 반복하세요.

앱을 열거나 초기화할 때 머리 방향을 360도 전체에서 무작위로 정합니다.
좌우를 번갈아 선택하도록 강제하지 않으므로 몇 번 연속 같은 쪽으로 갈 수 있습니다.
저장한 JSON에는 회차마다 사용한 난수 시드와 시작 각도도 함께 들어갑니다.
