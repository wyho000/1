# 화학물질 조건과 후각 모델

이 문서는 화면에 표시되는 용액 농도와 모델에서 계산하는 감각 입력을 구분합니다. 새 조건은 실제 농도별 행동 실험에 맞춰 학습한 모델이 아니며, FlyWire 해부학 데이터에서 화학물질별 행동 반응을 도출한 것도 아닙니다.

## 등록된 조건

| 물질 | 용액 조건 | 같은 물질 안에서 상대 자극을 정하는 기준 농도 |
| --- | --- | --- |
| 2-페닐에탄올 (2-phenylethanol) | 0.01%, 0.05%, 0.1% | 0.1% |
| 에탄올 | 1%, 5%, 10% | 10% |
| 아세트산 | 0.1%, 0.5%, 1% | 1% |
| DW (증류수) | 대조군 | 후각 입력 0 |
| PBS buffer | 1× 대조군 | 후각 입력 0 |

위 11개 조건에 기존 에틸 아세테이트·벤즈알데하이드·이산화탄소를 더해 총 14개의 기본 조건이 있습니다. 발생원은 조건과 별개로 최대 16개까지 배치합니다. 같은 물질과 농도라도 위치·상대 방출량·확산 범위·반응 가정은 발생원별로 설정합니다.

‘투페닐에탄올’은 2-페닐에탄올로 해석한 이름입니다. ‘1× PBS’의 ×는 작업 농도 배율을 뜻하는 표기이며 1%로 변환하지 않습니다. PBS의 조성, pH, 제품별 차이를 별도로 모사하지 않습니다.

## %는 용액 조건이며, 기체 농도가 아닙니다

용액 농도의 기준은 기본적으로 **미지정**입니다. 화면에서 **v/v** 또는 **w/v**를 선택하면 실험 조건의 메타데이터로 기록합니다. 기준을 선택하더라도 밀도·분자량 등을 이용한 물리적 단위 변환은 수행하지 않습니다. 용매 조성도 입력되어 있지 않으므로 자동으로 물 또는 다른 용매를 가정한 증기압 계산을 하지 않습니다.

실제 더듬이가 받는 자극은 용액 농도 외에도 용매, 온도, 용기, 노출 면적, 기류, 휘발성, 거리와 시간 등에 좌우됩니다. 이 앱은 이러한 기체 전달 조건을 보정하지 않습니다. 따라서 화면의 0.1%를 더듬이에 도달하는 0.1% 기체 농도나 특정 ppm 값으로 해석하면 안 됩니다.

각 새 유기물은 위 표의 기준 농도를 상대 자극 1의 기준으로 삼아 같은 물질의 낮은 농도에 더 작은 상대 자극을 부여합니다. 별도로 설정하는 **방출량(a.u.)**은 이 자극에 곱하는 상대 크기입니다. 거리와 확산 범위는 가우시안 농도장으로 반영합니다. 이것은 조건을 비교하기 위한 모델 규칙이며 실제 증발량이나 물질별 수용체 민감도를 측정한 결과가 아닙니다. 서로 다른 물질의 상대값 1이 실제로 같은 냄새 강도를 뜻하지 않습니다.

활성화된 유기물 발생원의 중심 자극은 `방출량 / 100 × clamp(용액 농도 / 기준 농도, 0, 1)`로 계산합니다. 방출량 역시 0–100으로 제한합니다. 예를 들어 다른 설정이 같다면 에탄올 1%, 5%, 10%는 각각 같은 기준의 0.1, 0.5, 1배가 됩니다. 농도 기준(v/v 또는 w/v)을 바꾸는 것만으로 이 비율은 달라지지 않습니다.

## 유인·회피는 조절 가능한 가정입니다

새 유기물의 반응 강도는 **−1에서 +1** 사이의 모델 설정입니다. 음수는 회피, 양수는 유인, 0은 방향 선호 없음입니다. 0으로 설정한 유기물은 냄새 감각 입력이 없어지는 것이 아니라, 해당 입력의 유인·회피 선호가 중립이 됩니다. 감각 및 적응에 따른 탐색 변화는 남을 수 있습니다.

기본값이나 조절값은 특정 성체 암컷 초파리 집단의 실험 결과에 맞춘 수치가 아닙니다. 높은 에탄올 또는 아세트산 농도가 어떤 임계값에서 반드시 회피를 일으킨다는 규칙을 임의의 실측 사실처럼 넣지 않습니다. 실제 반응은 조건에 따라 달라질 수 있으며, 앱의 반응 가정을 바꾸어 가설을 비교할 수 있습니다.

새 발생원에 처음 적용하는 예시 값은 2-페닐에탄올 **+0.50**, 에탄올 **+0.35**, 아세트산 **+0.40**입니다. 세 값 모두 편집 가능한 예시 유인 가정이며, 생물학적 유인 강도 순위나 실측 수치가 아닙니다. 같은 물질의 농도 조건을 바꾸어도 유인·회피의 방향을 자동으로 반전시키지 않습니다.

기존 에틸 아세테이트는 앱의 먹이 대리 자극입니다. 새로 추가한 2-페닐에탄올·에탄올·아세트산을 유인 자극으로 설정해도 실제 섭식이나 영양 공급을 뜻하지 않으며, 이들만으로 허기를 채우는 동작을 만들지 않습니다.

## DW와 1× PBS 대조군

DW와 1× PBS는 **이 모델에서 후각 자극을 만들지 않는 대조군**입니다. 발생원은 화면에서 선택·이동·비활성화할 수 있지만, 기체 확산을 뜻하는 안개와 후각 입력을 만들지 않습니다. 같은 난수 시드에서 다른 자극이 없으면 이 대조군만 배치한 초파리의 모델 궤적은 빈 환경과 같습니다.

이는 물이나 PBS가 모든 감각과 행동에 무조건 영향을 주지 않는다는 생물학적 주장과 다릅니다. 습도, 수분 탐색, 맛, 접촉, pH, 염도, 용액의 오염 또는 첨가제에 의한 효과는 이 후각 모델의 범위 밖입니다.

## 기록과 비교

기록 저장에는 발생원의 물질, 용액 농도 조건, 지정한 농도 기준, 상대 방출량, 위치, 확산 범위 및 반응 가정이 포함됩니다. 실험 보고나 비교에서는 모델 설정값과 실제 측정값을 구분해 기록하세요. 뇌 지도 활성도 또한 모델 출력이며 실제 신경 발화 기록이 아닙니다.
